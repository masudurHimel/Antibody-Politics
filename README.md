# Antibody Politics

A digital implementation of the Spanish card game **Virus!** — 1 human vs 3 bots, online multiplayer in Phase 2.

## Quick start

```bash
./run.sh
# Open http://127.0.0.1:8001
```

For dev with hot reload: `./run.sh dev` (open `:5173`).
